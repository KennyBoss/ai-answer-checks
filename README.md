# Проверки арифметики в ответах ИИ

Три маленьких калькулятора для проверки конкретных чисел в ответе ИИ:
суммы строк, изменения доли и ускорения одного этапа работы.
Они работают локально, без API, ключей и внешних библиотек.

Нужен Python 3.9 или новее. Скачайте файлы через **Code → Download ZIP**,
распакуйте архив и откройте терминал в этой папке. На Windows вместо
`python3` можно использовать `py`.

## 1. Совпадает ли итог с суммой строк

Учебные строки: 700 и 800. В ответе ИИ указан итог 1800.

```sh
python3 checks.py total 700 800 --claimed 1800
```

Результат:

```text
Сумма строк: 1500
Объявленный итог: 1800
Итог минус сумма: 300
```

Положительная разница означает, что объявленный итог больше суммы.
Нулевая разница подтверждает арифметику введённых строк, но не полноту
исходного документа. Пропущенную строку этот калькулятор не найдёт.

## 2. Проценты и процентные пункты

Доля выросла с 2% до 3%.

```sh
python3 checks.py percent 2 3
```

Это **+1 процентный пункт** и **+50% относительно исходной доли**.
Формула: `(новая доля − старая доля) / старая доля × 100%`.
Доли вводятся от 0 до 100; десятичный разделитель — точка.
При исходной доле 0% относительное изменение не определено.

## 3. Ускорение этапа и всей работы

Вымышленная задача: генерация занимает 8 секунд, остальные этапы — 32.
Ускорим только генерацию в 8 раз, сохранив остальное время.

```sh
python3 checks.py speed --generation 8 --other 32 --factor 8
```

```text
Общее время до: 40
Общее время после: 33.00
Сокращение общего времени: 17.50%
Ускорение всей задачи: 1.2121 раза
```

Формула нового времени: `время этапа / множитель + время остальных этапов`.
Все времена должны быть в одной единице. Множитель больше 1 ускоряет
этот этап; между 0 и 1 замедляет его. Это расчёт по заданным условиям,
а не измерение реальной модели, сети или компьютера.

## Запросы и проверка самого калькулятора

В [prompts.md](prompts.md) есть три готовых запроса, формулы и проверяемые
ожидаемые результаты. Чтобы проверить программу:

```sh
python3 -m unittest -v
```

В расчётах используется `decimal.Decimal` с точностью 50 значащих цифр
в командной строке. Очень длинные числа и бесконечные десятичные дроби
могут округляться; скорость и относительные проценты отображаются
с указанным числом знаков после точки. Не используйте этот учебный
инструмент как замену проверке исходных данных.

Все примеры вымышлены. Исходный код и текст подготовлены с помощью ИИ;
в комплекте есть воспроизводимые проверки. Лицензия — MIT.
